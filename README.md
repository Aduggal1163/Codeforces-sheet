## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/Aduggal1163/Codeforces-sheet.git
   ```
2. Navigate to the desired folder (`800`, `900`, `1000`) and compile the java files:
   ```bash
   javac "Problem Name.java"
   java Main
   ```
